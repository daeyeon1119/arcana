# ARCANA v73–v78 개발·검증 보고서

작성일: 2026-10-26  
대상: ARCANA 오프라인 단일 HTML 타로 앱 (v72 기반)

## 주요 변경 사항

- **v73** 질문의 답변 요구 유형을 `전망 / 행동 / 원인 / 비교 / 감정 정리 / 일반 성찰`로 분리. 복합적인 경우 보조 의도도 내부 기록. 단어 하나를 찾는 대신 문장 속 선택지, 시점, 부정·행동 표현의 일반적 패턴을 활용.
- **v74** 카드가 놓인 위치를 고려하여 카드 두 장 사이의 보강·대립·전환·대안 등의 상징적 관계를 평가. **실제 현실의 인과를 단정하는 것은 아님.**
- **v75** 해석 주장에 카드 위치, 대표 의미 구문과의 대조 결과를 내부적으로 연결. 문구 수준의 근거 확인이며 인간 수준의 논리·의미 검증기가 아님.
- **v76** 반복되는 본문과 행동 조언을 정리하고, 확인된 사실과 충돌하는 출력의 일부를 제한.
- **v77** '이미 연락함/연락 전', '확정된 결과/발표 대기', 선택/행동/원인 등 오류를 유발하는 한국어 변형 질문 검사.
- **v78** 제약 위반 시 기존 v72 엔진으로 돌아가는 보호 경로와 비교 검사.
- **이번 사용자 피드백 반영:** 카드 배열 선택 화면에서 중복된 **‘질문별 전용 배열’ 목록 제거**. 네 가지 일반 배열만 노출하고, `✦ 질문에 맞는 배열 자동 선택` 버튼을 추가. 버튼을 누르면 기존 관계·선택·결과 대기·진로 전용 배열 중 적합한 것을 내부적으로 선택하며, 일반 배열이 더 적합하면 3장 또는 5장을 선택. 선택 결과와 카드 수를 표시. 일반 배열 직접 선택 시 언제든 해제 가능.

## 검증 방법과 결과

### 독립 질문 의도 평가 — 48문항

아래 48개는 정규식/의도 분류 개선 과정에 사용하지 않은 별도 질문 세트입니다. 질문마다 의도 라벨을 지정하고 세 버전을 같은 조건에서 비교했습니다.

| 버전 | 기대 답변 유형 일치 | 비율 |
|---|---:|---:|
| v65 | 16 / 48 | 33.3% |
| v72 | 24 / 48 | 50.0% |
| v78 | **34 / 48** | **70.8%** |

단일 인공 작성 데이터셋이며 실제 사용자 전체에서의 정확도는 뜻하지 않습니다. v78에서도 **14건 오분류**가 남았습니다. 이 48건은 추후 개발/규칙 튜닝용으로 사용하지 않도록 분리했습니다.

### 개발·회귀 질문 260개 × 8종 배열 × 2개 카드 조합

- 개발용 질문 50개, 문구 변형 150개, 별도 오류 분석에 활용된 질문 60개: 총 260개 질문 입력(독립적인 260개의 원문 질문은 아님).
- **4,160개 리딩 생성**, 검사 도중 **실행 오류 0건**, 카드 참조 유효성 오류 **0건**.
- v78 코드의 강한 제약 위반으로 v72 엔진으로 되돌아간 사례 **0건**. 이 수치는 모든 결과가 의미적으로 올바르다는 뜻은 아닙니다.
- 동일한 질문과 배열에서 **첫 카드 한 장을 변경한 2,080쌍**을 비교했을 때 첫 응답 변경 **1,416쌍(68.1%)**, 첫 행동 조언 변경 **229쌍(11.0%)**. 첫 카드가 조언 위치가 아닌 배열도 많으므로 조언 변경률을 무조건 높이는 것이 목표는 아닙니다.
- **켈틱 크로스 520건 모두**에서 상세 해석에 10장의 카드 참조가 유지되었습니다. 카드 참조가 있다는 사실과 카드 의미의 해석 품질은 별개입니다.
- 개발에 반영한 50개 원문 질문의 의도 일치 **48/50**, 문구 변형 150개에서는 **144/150**. 이 자료는 검증 중 표현 규칙을 수정하는 데 사용했으므로 독립 정확도가 아닙니다.
- 처음 따로 만들었던 60개 질문도 오류 원인 분석과 규칙 수정에 사용해 최종 **57/60** 일치했지만 독립 평가치가 아닙니다.

### 화면 검사

실제 모바일 너비(390 px) Chromium에서 자동 추천 버튼, 숨겨진 전용 배열 목록, 일반 배열 수동 선택으로 되돌리기, 자동 적용 결과 표시를 검사했습니다.

시험한 자동 적용 사례:

| 질문 형태 | 자동 선택 결과 |
|---|---|
| 친구와 소원해진 상황 | 관계의 거리 · 5장 |
| 시험 결과를 기다림 | 기다림의 시간 · 3장 |
| A/B 비교 | 두 갈래의 선택 · 5장 |
| 커리어 전환 | 진로의 갈림길 · 5장 |
| 작품 문장 수정 | 심층 분석 · 5장 |
| 일상적 자기성찰 | 과거·현재·미래 · 3장 |

빈 질문에서는 자동 선택하지 않고 입력을 안내합니다. 카드 배열은 자동으로 선택하더라도 **카드 자체는 사용자가 직접 뽑습니다.**

## 주요 한계와 다음 과제

1. **의도 분류는 여전히 불완전:** 독립 48문항 중 14문항이 기대 유형과 다릅니다. 서술형 고민/복합 질문에서 오류가 남습니다.
2. **한국어 자연스러움:** 자동 구문 검사는 인간 평가를 대체하지 못합니다. 전문 타로 리더나 실제 사용자의 블라인드 자연스러움 평가를 수행하지 않았습니다.
3. **근거 역검증은 제한적:** 카드 ID가 존재하고 카드의 대표 의미 구문이 포함됐는지 주로 검사합니다. 조언이 실제로 가장 적절한 의미 해석인지 독립 검증하는 단계는 아닙니다.
4. **실험용 온디바이스 모델:** 과거 버전의 실험 옵션은 브라우저·기기마다 지원 수준이 다르며, 이번 성능 비교는 로컬 AI 모델을 활성화하지 않은 기본 해석 엔진 기준입니다.
5. **카드 이미지:** 단일 HTML 내장 상징 그림으로 오프라인 대체 가능하나 외부 RWS 원본 이미지를 처음부터 모두 오프라인 저장한 것은 아닙니다.

## 실행 및 데이터

- `ARCANA_tarot_v78.html`을 브라우저로 열어 사용. 리딩은 서버 API 호출 없이 기본 엔진으로 생성됩니다.
- 기존 브라우저 기록을 사용하는 경우 같은 저장소 출처에서 열어야 기록이 이어질 수 있습니다. 다른 브라우저/경로에서 열면 JSON 백업·복원을 이용하세요.
- ZIP에 v73~v78의 HTML, 재현용 v72 기반 코드, 개선 스크립트, 테스트 코드, 입력 질문 자료, 평가 출력 및 화면 미리보기가 포함됩니다.

**해석의 일관성·질문 의도 판별·화면 혼선은 일부 개선됐지만, 상담 자연스러움이나 예측 능력이 보증되는 제품은 아닙니다.** 타로는 상징적 성찰의 도구로 사용해야 하며 실제 미래·타인의 마음·검사 결과를 확인하는 수단이 아닙니다.
