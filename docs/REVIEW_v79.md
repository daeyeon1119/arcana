# ARCANA v79 개선 및 스트레스 테스트 보고서

작성일: 2026-10-26 (한국 시간)

## 후속 보완: 원본 카드와 최종 병합본

사용자의 원본 카드 표시 요청에 따라 자체 SVG 일러스트 생성·선택·대체 경로를 최종 앱에서 제거했습니다. Wikimedia Commons의 **1909 RWS “Roses & Lilies” 원본 스캔 78장**을 변경 없이 포함했습니다. [출처 및 파일별 해시](../assets/rws/README.md)를 기록했고, 각 JPEG의 바이트·SHA-1·SHA-256·픽셀 크기를 확인했습니다.

- 78장 전체가 원본과 같은 바이트로 디코딩되며, 이전 브라우저의 ‘내장 일러스트’ 설정이 남아 있어도 원본을 사용합니다.
- 외부 HTTPS를 차단한 도감·카드 상세 검사와, 단일 HTML만 빈 폴더로 복사한 오프라인 추첨·리딩·저장 기록 검사를 포함한 **이미지 검사 7항목**을 통과했습니다.
- 원본 JPEG 총 **22,124,802바이트**, 단일 HTML **30,627,482바이트**입니다. 원본을 재압축하거나 줄이지 않아 파일이 커졌습니다.
- 리딩 **1,024건**, 카드·방향 영향 **74건**, UI **25항목**을 다시 통과했습니다.
- ‘최근 일에 대한 의욕이 떨어진 까닭은 뭘까요?’에서 `뭘`이 행동 신호로 먼저 잡히던 퇴행을 수정했습니다. 기존 48문항은 최종 **37/48**, v78에서 맞던 문항이 틀리게 바뀐 경우는 **0건**입니다.

이 후속 수정에 기존 48문항의 알려진 퇴행을 사용했으므로 **최종 37/48을 독립 정확도로 제시하지 않습니다.** 아래 36/48 및 UI 24항목 등의 수치는 원본 카드 반영과 퇴행 보완 이전의 최초 검증 기록입니다. 최종 수치와 앱 SHA-256은 `test-results/stress-summary.json`, 이미지 검사는 `test-results/images-summary.json`에 있습니다.

향후 이 저장소에서는 사용자 요청에 따라 검증이 완료된 작업을 별도 승인 요청 없이 `main` 병합까지 진행합니다. 이 원칙과 원본 카드 요구를 `AGENTS.md`에 기록했습니다.

## 최초 v79 변경 결과

기존의 종이색·짙은 녹색 디자인과 직접 카드를 뽑는 흐름을 유지하면서, 질문의 사실관계·답변 초점·기록의 일관성을 보완했습니다. 서버 AI 호출을 추가하지 않았으며 단일 HTML 실행을 유지합니다.

| 발견한 문제 | 반영한 변경 |
|---|---|
| 두 선택을 묻는 한국어 어미, 걱정과 질문이 섞인 문장에서 의도를 놓침 | 마지막 명시적 요청, 비교 어미, 감정 서술을 구분하고 수동 초점 선택 추가 |
| 불합격 걱정을 확정 결과로 취급하거나 연락 전·답장 후를 혼동 | 결과의 확정 표현과 부정, 이미 보낸 연락과 받은 답장을 따로 판별 |
| 이전 시험 결과와 다음 도전을 혼동 | 과거 결과와 새 도전을 분리 |
| 수동 분야 선택과 자동 추천에 서로 다른 맥락 사용 | 분야·초점·자동 배열 추천·최종 해석에 같은 질문 분석 사용 |
| 본문과 펼친 근거, 후속 질문, 내보내기에 과거 엔진의 설명이 섞임 | 최종 보고서의 내용과 실제 카드 위치를 공통으로 사용 |
| 직장 피로에 취업 준비를 권하는 등 행동이 고민과 덜 맞음 | 피로·감정 돌봄, 이직 준비, 개발 작업, 생활비, 대출 등 상황별 실천 보완 |
| 질문 수정 후 기존 카드의 의미가 바뀔 수 있음 | 질문·설정 변경 시 진행 중인 추첨 초기화 및 안내 |
| 모바일 스위치의 입력 영역이 작고 포커스가 불명확함 | 48 × 44px 입력 영역, 스위치 이름·포커스 표시, 카드 창의 Tab 순환과 Escape 복귀 |
| 실험용 모델 패널과 중복 초점 선택이 답변 흐름에 혼재 | 초점 선택을 하나로 정리하고 실험 기능을 리딩 가이드로 이동 |
| 손상된 저장소나 중복 카드 기록이 화면을 깨뜨릴 수 있음 | 저장 자료 형태, 배열, 카드 ID·방향·중복 및 후속 질문 구조 검증 |

상대가 원치 않는 연락, 폭력, 응급 증상, 진료·약물·금전 판단에 대해서는 카드 상징을 실제 사실이나 결정을 증명하는 근거로 사용하지 않도록 응답을 구성했습니다.

## 1,024건 검사 설계

**128개 한국어 원문 질문 × 8종 배열 = 1,024개의 질문·카드 조합**을 생성했습니다. 서로 다른 원문 질문 1,024개를 검사했다는 의미는 아닙니다. 질문은 일·관계·가족·시험·창작·금전·건강·자기성찰을 포함하며, 전망·행동·원인·비교·감정·성찰의 기대 유형을 작성했습니다.

고정 시드 `790026`으로 중복 없는 카드 조합을 뽑았습니다. 78장 전체와 각 카드의 정·역방향 156개 상태, 1·3·5·10장 및 네 가지 전용 배열을 포함합니다. 실제 `index.html`을 Edge에서 실행해 테스트했고, 외부 HTTPS 요청을 차단하여 기본 해석과 내장 대체 그림이 네트워크 없이 실행되는 조건을 사용했습니다.

자동 검사는 실행 예외, 깨진 텍스트, 중복 본문, 유효하지 않은 카드 참조, 카드 누락, 방향 불일치, 이미 보낸 연락을 다시 권하는 표현, 확정 결과와의 충돌, 단정적 예측 표현, 경계·응급 상황 처리, 동일 입력의 재현성을 확인합니다. 단정적 표현 검사는 명시적인 문자열 규칙이므로 모든 부적절한 의미를 포괄하지는 않습니다.

## 결과와 해석

| 검사 | v78 | v79 |
|---|---:|---:|
| 개발 질문의 기대 의도 일치 | 102 / 128 (79.7%) | 128 / 128 (100%) |
| 개발 질문의 기대 분야 일치 | 112 / 128 (87.5%) | 128 / 128 (100%) |
| 사실·안전 조건이 지정된 시나리오 | 17 / 26 | 26 / 26 |
| 기존 별도 48문항의 의도 일치 | 34 / 48 (70.8%) | 36 / 48 (75.0%) |

- **1,024 / 1,024건**이 위의 구조·제약 검사를 통과했습니다. 실행 예외와 브라우저 페이지 오류는 0건입니다.
- 모든 배열의 모든 위치에서 카드 한 장만 바꾸거나 방향만 바꾸는 **74 / 74건**에서 해당 카드의 상세 근거가 바뀌었습니다. 모든 카드가 첫 문장이나 행동 제안을 바꾸어야 한다는 기준은 적용하지 않았습니다.
- **24개 UI 검사 항목**이 통과했습니다. 360·390·768·1440px 너비, 8종 배열의 실제 선택·공개, 기록 열기, 수동 초점 보존, 백업·중복 복원, 손상된 자료, 질문 변경 시 초기화, 키보드 스위치·카드 창을 포함합니다.

128개 질문은 개발 과정에서 오류 분석과 수정에 사용했습니다. **100%는 이 회귀 자료에서의 일치율이며 일반적인 질문 이해 정확도가 아닙니다.** 기존 별도 48문항의 결과를 보고 해당 문항에 맞춰 규칙을 수정하지 않았으며, 그 평가에서는 여전히 **12건의 의도 불일치**가 남습니다. 이 48문항도 작은 인공 작성 자료이므로 실사용 전체를 대표하지 않습니다.

## 답변 문장 검토

전체 1,024건의 출력은 압축 JSON Lines로 저장했습니다. 이 중 배열과 질문 분야가 고르게 바뀌는 간격으로 **32건**을 뽑아 실제 문장을 읽으며 질문 관련성, 밝힌 사실의 보존, 카드 의미·방향, 단정 여부, 행동의 구체성을 자체 검토했습니다. 전문 타로 리더나 독립 사용자의 블라인드 평가를 수행한 것은 아닙니다.

이 과정에서 직장 피로에 지원 준비를 권하는 문장, 생활비 질문에 시장 매수·매도 안내가 붙는 문장, 진료 준비 질문에 포괄적인 도움만 안내하는 문장을 발견해 보완했습니다. 정·역방향이 본문에서 보이지 않는 경우와 조사 연결도 정리했습니다.

최종 출력 예시는 다음과 같습니다. 전체 내용과 카드 조합은 `review-samples.json`에서 확인할 수 있습니다.

| 질문 | 실제 답변의 핵심 |
|---|---|
| 직장 생활이 너무 지쳐요 | 펜타클 8 역방향의 ‘완벽주의의 함정’을 성찰 관점으로 제시하고, 업무 중 줄이거나 도움을 요청할 일과 회복 시간을 구분하도록 안내 |
| 연인에게 이미 연락했는데 답장이 없어요 | 이미 마음을 전했다는 사실을 밝히고, 새 연락을 추가하기보다 기다리는 동안 자신의 일정을 유지하도록 안내 |
| 월세 지출을 어떻게 줄일까요 | 월 소득·고정비·변동지출을 구분하고 바꿀 수 있는 지출의 실제 절감액을 계산하도록 안내 |
| 치료 방법 A와 B 중 어느 쪽이 나을까요 | 카드로 치료법을 고르지 않고 목적·효과·위험·대안을 의료진과 비교하도록 안내 |
| 내시경 검사 전에 어떤 준비가 필요할까요 | 검사 기관의 준비 안내와 담당 의료진의 주의사항을 확인하도록 안내 |

카드의 단어와 질문 사이의 연결이 일반적이거나 반복적으로 느껴지는 답변은 여전히 있습니다. 카드 상징이 실제 사실의 원인·미래·타인의 마음을 알아냈다는 뜻으로 읽히지 않게 제한했습니다. 자동 분류가 맞지 않을 때는 분야와 답변 초점을 직접 변경할 수 있습니다.
