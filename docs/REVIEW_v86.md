# v86 · 확인 상태를 실제 대상과 요청에 연결

질문에서 확인했다고 밝힌 대상과 아직 확인하지 못한 대상을 분리해 준비·수정·설명에 적용합니다. 한 절의 ‘이미 확인한 날짜와 아직 대조하지 못한 장소’도 각각 다른 상태로 유지합니다. 카드가 사실의 정확성을 검증했다는 뜻은 아닙니다. 유료 서비스·외부 AI API·특정 PC의 서버를 추가하지 않으며, 무료 오프라인 해석과 원본 RWS 78장을 유지합니다.

## 구조 개선과 개발 검토

확인 술어와 대상의 원문 위치를 함께 보존합니다. 정·부정, 수식절·서술절, 검토 중·확정 전·완료 표현, 시점·주체·전언·가정을 구별합니다. 상충 상태는 임의로 결정하지 않으며 명시적 정정과 현재 시점을 우선합니다. 대상을 연결할 수 없는 술어는 별도로 남깁니다. 이중 부정을 확정 사실로 단순 반전하지 않습니다.

조언에는 짧은 대상별 안내를 한 번 연결합니다. 그 안내와 겹치는 일반 확인 문장만 줄이고, 자료의 목적·읽는 순서·수정·완료 방법과 전문 내용의 출처 확인은 유지합니다. ‘고치고 설명하기’ 같은 접속 요청과 생략된 공동 대상을 제한적으로 처리합니다. 앞 절과 같은 준비 작업이나 ‘이를’ 같은 지시어도 확인합니다. ‘이유를 어떻게 설명할까요’를 원인 추측으로 바꾸지 않습니다. 다른 명시적 대상이나 새로운 문장에 공동 대상을 무조건 확장하지 않습니다.

[개발 질문 8개 × 배열 8종의 실제 출력](../test-results/verification/development/review.html)에는 이전 버전의 날짜/장소 실패와 상태 반전 쌍이 포함됩니다. 첫 개발 실행에서는 자료 수정과 설명 중 하나가 빠졌으며, 이를 보고 접속 술어와 공동 대상을 보완했습니다. 작성자 검토 범위는 별도 JSON에 기록합니다.

## 구현 고정 뒤 첫 평가

후보 `5f549a2`의 HTML 해시 `abafb8b1d74732e291d46b481544e38f0da02b8e13e45a9e7d15df694b684981`을 고정하고, `3463947`에서 새 질문 16개를 작성한 뒤 같은 카드·방향·배열로 v85와 후보를 각각 128회 실행했습니다. 점자 전시·해양 표본·복원 기록·제본·음성 해설처럼 분야와 표현을 바꾸고, 상태·주체 반전, 생략, 정정, 전언, 가정과 복합 요청을 포함했습니다. 구현을 아는 작성자의 진단이므로 독립적인 블라인드·전문가 평가라고 부르지 않습니다.

[첫 출력과 실패](../test-results/verification/first/review.html)는 `2f76ec2`에서 수정 전에 보존했습니다. 원본 출력 SHA-256은 `0f97498364ce94959a852f87768e820b9b14727d01815178289d6d0a10d6613e`입니다. 대상·상태 계약은 128개 중 80개만 통과했고, 6개 질문의 48개 배열 변형이 실패했습니다. 첫 요약과 실제 출력은 덮어쓰지 않습니다.

16개 다섯 장 배열의 핵심 답변을 읽으니 계약 실패 외의 한계도 있었습니다. 검증 완료의 다른 표현을 놓치고, ‘오늘은’을 사람 주체로 읽으며, 파일명을 잘랐고, 생략된 쪽수 미확인을 누락했습니다. 이중 부정에서는 ‘게 아닙니다’를 확인 대상으로 출력했습니다. 지도 수정·이유 설명은 자료 대상을 잇지 못하고 설명을 원인 탐색으로 바꿨습니다. 지도 사례의 원문 사실 자체는 추출돼 있었으므로, 초기 검토 노트의 주체 처리 추정은 최종 진단과 구별합니다.

이를 보고 문법·경계·대상 연결을 보완했습니다. [이후 실제 출력](../test-results/verification/regression/review.html)은 알려진 회귀 자료입니다. 최종 구현의 새로운 미사용 평가로 세지 않습니다. 생략은 바로 이어지는 대비절의 ‘아직’처럼 선행 확인 술어가 명확할 때만 연결합니다. 일반적인 ‘아직’ 문장이나 불확실한 이중 부정을 임의로 완료/미완료로 확정하지 않습니다.

## 검증 범위와 남은 한계

v84의 g10/g11 회귀 계약은 전체 확인 문장을 그대로 인용하는 형태에서 대상·상태가 실제 조언에 연결되는지 확인하는 형태로 바꿨습니다. 중복 원문을 줄인 출력 형식의 변화이며 확인/미확인의 의미 요구는 유지합니다. 원래 첫 질문·첫 출력은 변경하지 않았습니다.

360px 화면에서 실제 추첨·공개·내보내기·저장, 날짜/장소 상태, 상충 상태와 복합 요청을 확인합니다. 기기 일치 자료에는 이 버전의 날짜/장소·생략·수정 이유 질문을 추가했습니다. 3개 Chromium 화면 프로필 각각 104개 질문·카드·방향·배열·설정 조합의 전체 보고서, 오프라인, 기록 이동과 업데이트 경로를 검사합니다. CRLF 소스 사본의 재빌드도 배포 파일과 정확히 일치하는지 확인합니다. 실제 공개 배포 검증은 별도 결과 파일로 남깁니다. 화면 프로필은 물리적 휴대전화·Safari 검증이 아닙니다.
