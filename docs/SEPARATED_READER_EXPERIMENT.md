# 질문 답변과 카드 관점의 분리 후보

카드 없이 질문의 요청별 실질적인 도움을 먼저 생성하고, 다음 단계는 카드별 관점과 연결만 추가하는 실험 코드입니다. 두 번째 단계가 첫 답변·실천을 덮어쓰지 못하도록 별도 출력 계약을 사용합니다. 두 단계의 첫 원문도 따로 보존합니다.

현재 합성 계약 검사 25개만 통과했으며 **실제 모델 답변은 아직 생성·검토하지 않았습니다.** 의미의 정확성을 보장하는 검증기가 아닙니다. 카드 문장과 첫 답변 어느 쪽에도 사실 창작이 남을 수 있습니다. 기본 앱과 빌드에는 포함하지 않았습니다.

사용자가 외부 기기에서도 동일 수준의 작동을 요구했으므로 이 PC의 대용량 모델만으로 제품 목표를 달성했다고 인정하지 않습니다. 이 후보는 별도 연구 브랜치에 보존하고, 먼저 공개 웹 앱의 기기 간 동작과 무료 배포를 보완합니다. 향후 채택은 실제 해석 품질과 외부 기기에서 이용 가능한 동일 경로를 함께 검증해야 합니다.
