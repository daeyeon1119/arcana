# v83 · 질문에서 요청한 작업과 대상 우선

해석 엔진을 무료·오프라인 JavaScript 안에서 보완하므로 특정 PC의 모델이나 유료 API를 요구하지 않습니다. 원본 RWS 78장과 8종 배열은 유지합니다. 전문 해석가 수준에 도달했다는 의미는 아닙니다.

## 개선하는 구조

분야는 건강·금전인데 사용자가 원하는 것은 설명·조건 확인·질문 준비·마음 돌보기인 경우, 기존 분야별 주의문이 실제 요청을 덮는 문제가 있습니다. 요청한 작업을 먼저 식별하고, 기존 맥락별 조언 가운데 작업이 맞는 것을 선택한 뒤 실제 카드 근거를 연결합니다. 기존 조언이 잘 맞으면 구체성을 버리고 일반 문장으로 교체하지 않습니다.

배경의 ‘바꾸려면·시작할 때’와 실제로 묻는 동사를 구별합니다. 실제 요청이 ‘어떻게 할까요’처럼 생략됐을 때는 명시된 목적을 이어받습니다. ‘나누다·조정하다’는 단어만으로 분담·우선순위를 정하지 않고 그 대상도 확인합니다. 인용문은 요청이나 사실의 근거로 다시 사용하지 않습니다.

작업별 기존 조언의 출처를 기록하고 기존 카드 통합 해석도 함께 유지합니다. 같은 작업이어도 대상과 전제가 다른 조언은 재사용하지 않도록 보완했습니다. 자료 편집·설명을 가족 상담·투자 결정으로 바꾸지 않고, 금융 의미가 확인되지 않은 ‘대출’에 상환액 조언을 붙이지 않습니다. 명시된 혼자 작업·협업 여부와 접수 완료 단계를 확인합니다. 질문 준비와 즉시 재연락을 구별합니다. 인용된 복약·보장 문구는 실제 개인의 행동으로 읽지 않으면서 내용 검증과 편집 지원을 함께 제공합니다. 설명과 감정 대처를 함께 요청할 때 두 관점을 남깁니다.

이는 제한된 한국어 규칙과 편집한 조언입니다. 범용 언어 이해나 전문가 동등성의 증거가 아닙니다. 모든 질문을 이해했다고 주장하지 않습니다.

## 개발 검토와 별도 첫 평가

구현 전후의 기존 320개 질문을 재생성했습니다. 자동 검사 통과 뒤에도 바뀐 문장을 직접 읽으며, 배경 동사를 실제 작업으로 오해하거나 구체적인 조언을 일반 문장으로 바꾸는 퇴행을 찾았습니다. 이 자료를 보고 수정했으므로 개발·회귀 자료입니다. 단위 검사와 개발 질문 12개 × 배열 8종도 독립 평가로 세지 않습니다.

구현을 `860e8ee`로 고정한 다음 새 질문 32개를 작성했습니다(`ef1a29e`). 같은 카드·정역방향·배열에서 v82.1과 후보를 각각 256번 실행했습니다. [첫 결과와 검토](../test-results/task-policy/first/review.html), [검토 범위](../test-results/task-policy/first/review-scope.json)를 보존했습니다. 핵심 답변 32개와 켈틱 4질문의 카드 설명 40개·통합 단락을 직접 읽었으며 모든 256개 상세 답변을 읽었다고 주장하지 않습니다.

첫 라우팅 검사에서 27건이 실패했고, 검사상 맞게 분류된 답변에도 책/은행 대출 혼동, 혼자 처리한다는 사실 누락, 문서 편집을 가족 걱정으로 치환, 감정 요청 누락이 있었습니다. 첫 결과는 수정하지 않았습니다. [수정 뒤 256개 회귀 출력](../test-results/task-policy/regression/review.html)과 바뀐 핵심 답변 14개의 검토를 별도로 남겼습니다. 회신 전 질문 ‘준비’를 허용한 계약 변경은 [회귀 기대 변경 이유](../tests/task-policy-regression-expectations.json)에 적었고 최초 기대값은 유지했습니다. 라우팅·참조 통과는 의미 품질 점수가 아닙니다.

개발 속성 검사 70개와 질문 문법 검사 236개는 구현 검증입니다. 기존 320개, 개발 질문 12개 × 8종, 기존 스트레스 검사 1,024건도 이미 알려진 자료이며 새로운 독립 평가로 세지 않습니다. 전체 검사에서 의료 마음 돌보기의 판단 제한이 사라지는 퇴행을 찾아 수정했습니다. 의료진에게 질문을 준비하는 답변도 인정하도록 검사에서 의료진·약사 참조를 확인합니다. 기존 의료 질문의 구체적인 준비 조언이 회신 대기용 일반 문장으로 바뀌지 않도록 재사용 조건도 구별했습니다.

두 번째 엔진을 `82cfae2`로 고정한 뒤 새 질문 16개를 작성했습니다(`0218191`). [첫 128개 출력과 16개 핵심 답변 검토](../test-results/task-policy/fresh/review.html)를 보존했습니다. 라우팅 16건 실패 외에도 현재 동료를 과거 혼자 작업으로 오해하거나, 개인 연습에 제품 사용성 조언을 재사용하고, 여러 실천 요청 중 하나를 빠뜨리는 오류가 나왔습니다. 이 결과를 보고 현재/과거 절을 나누는 참여자 처리, 병렬 실천 요청, 요구 자격·질문 준비 표현, 기존 조언의 전제 확인을 보완했습니다. [수정 후 출력](../test-results/task-policy/fresh-regression/review.html)은 회귀 자료입니다. 새로 본 모든 질문을 이해했다거나 48개 질문이 최종 구현에 대한 미사용 평가라고 주장하지 않습니다.

금액을 이미 확인했는지에 따른 답변 차이, 구체적인 대상별 조언과 카드 상징의 연결은 여전히 부족합니다. 규칙이 아는 표현 밖의 주체·부정·생략·복합 요구에는 오류가 남을 수 있습니다. 독립된 전문 해석가 평가는 없으며 라우팅이나 자체 검토를 전문가 동등성 증거로 사용하지 않습니다.

응급·연락 거절·위험 상황과 약·치료 변경 같은 임상 판단은 기존 제한을 유지합니다. PC·모바일 화면 프로필과 [공개 배포의 실제 다운로드·오프라인 검사](../test-results/public-83-check.json)에서 동일 버전·입력의 해석 일치를 확인했습니다. 실제 휴대전화·Safari와 전문 해석가의 독립 평가는 아직 없습니다.

[최종 빌드 검사 묶음](../test-results/v83-validation.json)은 같은 HTML 해시로 저장된 실제 결과를 확인합니다. 기존 54개 진단 자료에는 두 분야 라벨 불일치가 남아 있으며, 통과 항목과 구분해 함께 기록합니다. 핵심 품질·외부 기기 목표를 완수한 뒤 한국어·일본어·영어 번역을 제공하라는 후속 순서도 유지합니다. 이번 버전에 번역 기능이 구현됐다는 뜻은 아닙니다.
