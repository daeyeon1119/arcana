# ARCANA v80 · 실제 질문 검토와 카드 매트 개선

2026-10-26

## 실제로 생성하고 읽은 답변

이전의 128개 질문 × 배열 조합 검사와 구분해, **내용이 서로 다른 원문 질문 320개**를 새로 작성했습니다. 이직·협업·연애·친구·가족·시험·학습·창작·개발·금전·건강·선택·감정·사업·결과 대기·일상의 16개 분야를 포함합니다. 수정 전후에는 질문뿐 아니라 카드와 정·역방향도 똑같이 고정했습니다.

핵심 답변 320개를 모두 읽었고, 8종 배열을 고르게 포함하는 40건의 카드별 상세 근거도 확인했습니다. 주요 수정 뒤에는 문제 사례의 새 답변을 다시 읽었습니다. [320개 전체 답변 비교](../test-results/editorial/review.html)에는 질문·실제 출력·카드 조합·상세 근거·20개 주요 수정 메모가 있으며, 분야와 내용으로 검색할 수 있습니다.

이것은 에이전트 자체 검토입니다. 전문 리더의 블라인드 평가를 수행했다는 뜻은 아닙니다. 질문은 개발 중 수정에 사용했으므로 최종 일치율은 회귀 수치로 봐야 합니다.

## 실제로 찾고 고친 문제

| 질문의 상황 | 이전에 나온 문제 | 보완 |
|---|---|---|
| 동료가 사과함 | 사용자가 먼저 연락했고 아직 답을 못 받았다고 바꿈 | 행동한 주체와 받은 답을 구분 |
| 서로 연락한 뒤 다음 약속 제안 | 답장이 없다는 전제로 기다리라고 함 | 상호 연락을 반영 |
| 자녀가 대화를 피함 | 친구 한 사람에게 기대지 말라는 조언 | 자녀가 편한 시간·방식을 묻는 대화 제안 |
| 빌려 간 물건 반환 요청 | 거리감의 이유를 지켜보라는 조언 | 물건·필요 날짜·반환 방법을 구체화 |
| 이미 받은 입사 제안 | 지원 준비를 다시 권함 | 첫 출근의 장소·시간·서류 확인 |
| 업무량 협의 | 이직하거나 떠날 이유를 적으라고 함 | 마감·소요 시간·우선순위 협의 |
| 과제를 이미 제출함 | 제출 기준과 마감을 다시 점검하라고 함 | 피드백과 다음 학습으로 초점 이동 |
| 원고를 이미 보냄 | 초고나 장면 수정에 머묾 | 접수·답변 일정과 다음 작업을 구분 |
| 여행 준비 | 취약한 시험 문제를 풀라고 함 | 이동·숙박·일정의 확인으로 수정 |
| 복약 후 불편함 | 일반 자기성찰로만 분류 | 의료적 판단을 카드로 하지 않고 의료진과 확인하도록 처리 |

‘비교하느라 위축된다’는 감정 서술, ‘존중’의 ‘중’, ‘답장도 받았다’, 마지막 문장에 덧붙인 사실 등도 구별하도록 보완했습니다. 답변에서는 실제 제안을 앞에 두고, 카드 이름과 의미를 일관된 문장으로 연결했습니다. 단일 카드별 근거를 줄였고, 여러 카드의 다른 의미를 단지 같은 행동 태그라는 이유로 반복 주제라고 부르지 않도록 정리했습니다.

## 카드 매트

이전 배치에는 5장 배열의 빈 첫 행, 선택 배열의 빈 열, 켈틱 크로스의 고정 7열·5행이 남아 있었습니다. 작은 화면에서도 고정 폭과 행 높이를 그대로 써서 카드 사이가 벌어지고 매트가 옆으로 넘쳤습니다.

- 빈 행과 열을 줄이고 실제 카드 크기에 맞춘 자동 행 높이를 사용합니다.
- 간격은 데스크톱 12px, 모바일 8px, 모바일 켈틱 6px입니다.
- 5장은 넓은 화면에서 한 줄, 작은 화면에서 3장+2장으로 배치합니다.
- 선택 배열은 3열 3행, 켈틱 크로스는 교차 카드와 오른쪽 4장 기둥을 유지한 4열 배치로 조정했습니다.
- 도감 원본·정역방향은 그대로 유지합니다. 펼친 카드 아래에 반복되는 **카드 이름을 제거**하고 배열의 자리 이름만 표시합니다. 스크린리더 이름과 방향은 보존합니다.
- 실제 추첨 매트, 해석의 배열 미리보기, 저장 기록에 같은 배치 규칙을 적용합니다.

390px 화면에서 내부 너비 336px인 매트의 측정 결과:

| 배열 | 이전 가로 폭 | 수정 가로 폭 | 이전 높이 | 수정 높이 |
|---|---:|---:|---:|---:|
| 3장 | 418px | 328px | 262px | 214px |
| 선택 5장 | 651px | 328px | 912px | 659px |
| 켈틱 10장 | 698px | 336px | 1056px | 706px |

[화면 비교 및 크기 측정](../test-results/mat/)에 원본 자료가 있습니다. 5장 일반 배열은 가로 스크롤 대신 2줄로 바뀌므로 모바일 높이는 늘지만 5장 전체가 화면 너비에 들어옵니다.

## 검증과 남은 한계

- 새 질문 320개 생성에서 실행 오류 0건. 작성한 기대 의도 일치는 **267/320 → 320/320**, 분야는 **247/320 → 303/320**입니다. 분야 기대값과 다른 17건은 그대로 남겨 두었습니다. 일부는 질문에 직업·학습 등의 맥락이 부족한 경우이며, 모두 의미적으로 올바르다고 판정한 것은 아닙니다.
- 주체·답장·자녀·여행·입사·업무·복약 등 실제 발견한 오류에 대한 12개 회귀 검사를 추가했습니다.
- 기존 리딩 1,024건과 카드·방향 영향 74건, 브라우저 UI 25항목, 원본 이미지 7항목을 다시 검사해 모두 통과했습니다.
- 카드 매트는 360·390·768·1440px에서 8종 배열, 총 32개 배치를 확인해 가로 넘침과 중복 카드 이름이 없었습니다. 실제 결과는 `test-results/mat/after-geometry.json`에 저장했습니다.

기본 엔진은 여전히 규칙과 정해진 카드 의미로 동작합니다. 문장을 자연스럽게 고치는 일과 전문 리더처럼 복합 질문을 이해하고 여러 카드를 통합하는 일은 같은 검증이 아닙니다. **전문가 수준 달성을 선언하지 않습니다.** [지속 개선 평가 기준](READING_QUALITY.md)에 여섯 평가 축과 독립·전문가 비교 절차를 정리했습니다.

현재 출력과 실패·모호한 사례를 보존하면서 질문 해석, 카드의 통합적 흐름, 구체적인 조언을 다음 버전에서도 개선합니다. 검증한 변경은 사용자 지시에 따라 `main`에 병합합니다.
