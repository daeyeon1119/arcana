# 전문 해석가 수준을 향한 평가 기준

사용자가 정한 최종 목표는 다양한 질문에서 전문 타로 해석가에 가까운 해석을 내는 것입니다. 실행 오류가 없거나 카드 이름이 포함됐다는 사실만으로 이 목표를 달성했다고 판단하지 않습니다.

**특정 질문에서만 좋은 답변을 내서는 안 됩니다.** 개발 예문의 표현에 맞는 분기를 늘리는 것보다, 처음 보는 질문의 뜻과 사실을 보존하고 카드 근거를 적용하는 구조를 우선합니다. 같은 뜻을 다른 말로 쓴 질문에서는 핵심 해석이 유지되고, 부정·주체·결과 확인 여부가 바뀌면 해당 부분의 해석은 달라져야 합니다.

## 여섯 가지 평가 축

| 평가 축 | 확인할 내용 |
|---|---|
| 질문 이해 | 전망·행동·원인·비교·감정·성찰 가운데 실제로 요청한 답을 주는가. 복합 질문에서 마지막에 명시한 요구와 배경 설명을 구별하는가. |
| 사실 보존 | 누가 행동했는지, 이미 한 일인지, 답을 받았는지, 결과가 확정됐는지를 바꾸거나 없는 사건을 만들어 내지 않는가. |
| 카드 근거 | 실제 카드·정역방향·배열 위치를 반영하는가. 자리의 의미와 카드의 상징을 구별하며, 한 카드나 방향이 바뀌면 해당 설명도 바뀌는가. |
| 통합 해석 | 여러 카드를 단순 나열하는 데 그치지 않고 공통 흐름·긴장·조언을 연결하는가. 서로 다른 의미를 같은 주제라고 잘못 묶지 않는가. |
| 조언 | 사용자가 지금 선택할 수 있는 구체적인 행동을 제안하는가. 건강·금전·타인의 동의 등을 카드로 사실 확인한 것처럼 다루지 않는가. |
| 문장 | 조사·주어·시제가 자연스럽고 질문과 무관한 분야의 문장이 끼지 않는가. 서두와 주의 문구가 반복되어 본래 답을 가리지 않는가. |

각 축은 향후 블라인드 비교에서 0(심각한 문제), 1(큰 보완 필요), 2(사용 가능하나 일반적), 3(맥락에 잘 맞음), 4(전문가와 비교해도 설득력 있음)로 평가합니다. 점수만 적지 않고 질문·카드 위치·문장에서 근거를 함께 표시합니다.

## 평가 자료의 구분

- **개발·회귀 자료:** 수정에 사용한 질문입니다. 128개 기존 질문과 새 320개 질문이 여기에 해당합니다. 여기에 잘 맞아도 임의의 새 질문 전체에서 같은 성능을 보장하지 않습니다.
- **고정 후 별도 평가:** 구현을 먼저 고정하고, 수정에 쓰지 않은 질문과 카드 조합에서 답변을 비교합니다. 결과를 보고 규칙을 조정하면 해당 자료는 그 뒤부터 회귀 자료로 옮깁니다.
- **전문가 비교:** 동일한 질문·카드·방향·배열을 전문 리더와 앱에 주고, 어느 쪽의 답인지 가린 상태에서 위 기준으로 비교합니다. 아직 이 검증을 수행한 것은 아닙니다.

비교할 때는 질문과 카드 조합을 그대로 유지합니다. 결과를 유리하게 만들려고 카드를 다시 뽑거나 모호한 사례를 결과에서 삭제하지 않습니다. 실패·일반적인 답변·분야 판별이 애매한 경우도 남깁니다.

## 현재의 상태와 다음 개선

v80은 실제 질문 320개를 생성해 핵심 답변을 읽고, 8종 배열을 포함한 40건의 상세 설명도 확인했습니다. [실제 출력 비교](../test-results/editorial/review.html)와 검토 메모를 보관합니다. 주체 혼동, 이미 한 일을 다시 권하는 문제, 분야가 다른 조언과 딱딱한 문장을 보완했습니다.

기본 엔진은 여전히 로컬 규칙과 정해진 카드 의미를 사용합니다. 드문 표현·복합 질문·주어진 정보가 적은 질문의 해석, 여러 카드가 만드는 하나의 이야기에는 일반적인 표현이 남을 수 있습니다. 이것을 전문가 수준을 달성했다는 결과로 포장하지 않습니다.

다음 개선은 실제 질문에서 의도·사실·알 수 없는 것을 구조화하는 단계, 위치와 정역방향을 유지하는 통합 해석 단계, 문장 편집 단계, 출력 검증 단계를 분리하는 데 초점을 둡니다. 의미 해석을 넓히는 생성 모델을 도입하는 경우에도 카드 근거와 사실 보존 검증은 유지해야 하며, 모델·비용·개인정보 처리 방식은 구현에 맞게 명시해야 합니다.

v81은 카드별 정·역방향 세부 주제와 배열 역할을 바탕으로 연결 근거를 구성합니다. 개발 질문 24개·72개 조합과 별도로, 구현을 고정한 뒤 새 표현 54개를 8종 배열에서 평가했습니다. [첫 실행의 실패와 실제 출력](../test-results/generalization-v81/review.html)을 보존합니다. 다른 표현에서 받은 답과 대기 상태를 놓치고, 정보 부족과 복합 요구에 대응하지 못하는 문제가 남았습니다. 첫 실행 결과를 보고 비교 의도 퇴행을 고친 뒤의 재실행은 회귀 자료입니다. 자세한 범위는 [v81 보고서](REVIEW_v81.md)에 구분합니다.
