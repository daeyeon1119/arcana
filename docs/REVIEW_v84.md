# v84 · 질문의 조건과 카드 근거 연결

질문에 적은 시간·예산·수량·선택지·확인 상태를 원문 위치와 함께 읽고 실제 요청에 연결합니다. 무료 오프라인 JavaScript로 동작하며 유료 API나 특정 PC의 모델 설치를 요구하지 않습니다. 원본 RWS 78장, 정·역방향, 배열 위치와 카드 간 통합 해석을 유지합니다. 전문 해석가 수준에 도달했다는 의미는 아닙니다.

## 구조 개선

`reading-evidence.js`는 인용·부정·가정·전언·현재와 과거·주체·선택지 범위를 구분하여 원문 근거를 기록합니다. 준비에 쓸 시간과 회의 진행 시간을 실제 요청과 대조합니다. 근거가 모호하면 하나를 임의로 고르지 않습니다. 시각·날짜를 작업 시간으로 바꾸거나 금액을 임의 계산하지 않습니다. 확인한 내용과 확인 중인 내용을 각각의 원문 대상에 연결합니다.

선택지에 쓴 수량은 개인의 공통 자원으로 재사용하지 않습니다. 명시한 A/B 라벨을 유지하고 뒤에서 정정한 정의를 사용하며, 미정인 안은 추첨 전에 내용을 묻습니다. 보충 답변은 원래 질문 뒤에 이어 최신 내용을 반영합니다. 세 개 이상의 선택지는 각각 보존하되 현재 두 안 비교 배열의 카드에 임의로 셋째 안을 배정하지 않고 공통 기준으로 읽습니다. 별도의 세 안 개별 비교 배열을 구현한 것은 아닙니다. 파일명의 점 때문에 선택지 설명이 잘리지 않게 했습니다.

`reading-bridge.js`는 실제 카드의 정·역방향 주제와 요청 종류를 연결하는 편집한 관점입니다. 개별 카드와 두 카드 관계의 근거를 구별합니다. 비교 배열의 A/B 카드를 일반적인 두 카드 긴장 관계로 재해석하지 않습니다. 기존의 구체적인 준비·수정·확인 절차 전체를 보존한 뒤 카드 관점을 더합니다. 기존 조언을 첫 문장만 남기고 버리거나 조언 카드의 관점을 다른 카드 둘의 근거로 표시했던 개발 중 오류도 수정했습니다.

## 첫 평가와 회귀 자료

후보 `f6a47a8`을 고정한 뒤 `62cdaa0`에서 새 질문 24개를 작성했습니다. 같은 카드·방향·배열로 v83과 후보를 각각 192회 실행했습니다. [첫 실제 출력](../test-results/grounding/first/review.html), [검토 범위](../test-results/grounding/first/review-scope.json), [질문별 검토](../test-results/grounding/first/review-notes.json)를 보존합니다. 첫 HTML 해시는 `3703b9fb220189afd280c0c9eba461cf9612ab2af70b1de9a365cd2fc82f0cd8`입니다.

첫 192회는 당시 기계적 검사를 모두 통과했지만, 핵심 답변을 읽자 다음 의미 오류가 나왔습니다. 예산·수량 미활용, 확인 대상이 반대여도 같은 답, 미정인 B를 제공된 안으로 취급, C를 B에 합침, 정정 전 A의 시간 사용, 회의 시간을 준비 시간으로 사용, 긴 파일명 뒤 설명 누락입니다. 숫자를 추출하거나 원문 위치를 맞춘 것만으로 질문을 적절히 해석했다고 볼 수 없었습니다. 실패를 포함한 첫 출력과 요약은 바꾸지 않았습니다.

이를 보고 수정한 [현재 192회 출력](../test-results/grounding/regression/review.html)은 알려진 질문의 회귀 자료입니다. 최종 구현에 대한 새로운 미사용 평가가 아닙니다. 5장 핵심 답변 24개와 추가 비교 배열 답변을 읽었으며 모든 192개 상세 변형을 직접 검토했다고 주장하지 않습니다. [현재 검토 범위](../test-results/grounding/regression/review-scope.json)에 실제 읽은 범위를 기록합니다.

기존 320개 출력도 재생성하고 [바뀐 핵심 답변 12개](../test-results/editorial/v84-review.html)를 수정 전과 비교했습니다. 수정 목록·출처 확인·상대의 이해 확인처럼 유용한 후속 절차가 사라지는 퇴행을 찾아 보완했습니다. 기존 v83 질문 48개 × 배열 8종의 회귀 자료도 별도 v84 폴더에 보존합니다. 개발용 카드·작업 조합 검사는 질문 수나 의미 품질 점수로 세지 않습니다.

## 검증 범위와 남은 과제

[최종 검사 묶음](../test-results/v84-validation.json)은 동일 HTML 해시의 스트레스 1,024회, 기존 질문 320개, 통합 해석 72회, 원본 78장, 매트·실제 화면 조작·오프라인·기록·출력 일치 결과를 연결합니다. 360px 화면에서 보충 질문, 선택지 추가, 긴 파일명, 원문 마크업과 `$&`·`$$` 표시도 실제 추첨·공개·내보내기로 확인합니다. 이 횟수들은 서로 다른 독립 평가 질문 수가 아닙니다. 기존 54개 진단의 두 분야 라벨 불일치도 숨기지 않습니다.

이 파서는 제한된 한국어 문법과 편집한 문장을 사용합니다. 새 표현의 주체·생략·부정·복합 요구·복잡한 정정 관계에서 오류가 날 수 있습니다. 조건을 보존하는 것에 비해 대상별 구체적인 해석과 조언은 여전히 일반적이고, 긴 답변의 반복도 남습니다. 320개 중 다시 읽은 141·173·293번에서는 비교가 아닌 질문에도 직접 선택한 비교 배열의 A/B 해석이 남고, 조건부 대인관계 관점이 덜 필요한 곳에 붙습니다. 이 문제를 해결했다고 기록하지 않습니다. 모든 질문을 이해하거나 전문 해석가와 동등한 수준에 도달했다고 주장하지 않습니다. 독립된 전문 해석가 평가도 아직 없습니다.

기기 간 일치는 같은 버전·질문·카드·방향·배열·설정을 기준으로 검사합니다. 모바일 화면 검사는 Chromium 에뮬레이션이며 실제 휴대전화·Safari 검증과 구별합니다. 실제 공개 배포의 다운로드·오프라인 검증은 별도 결과로 남깁니다. 핵심 품질과 외부 기기 목표를 완수한 뒤 한국어·일본어·영어 번역을 진행한다는 순서를 유지합니다.
