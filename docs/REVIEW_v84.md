# v84 후보 · 질문의 근거와 카드 관점 연결

현재는 개발·검증 중이며 공개 앱에 배포한 결과가 아닙니다. v83의 실제 검토에서 시간 조건을 쓰지 않거나 카드 이름·주제와 일반 조언이 따로 놓이는 문제가 남았습니다. 카드·방향·배열과 원문 근거를 함께 추적하는 구조로 보완합니다. 유료 API, PC의 모델 서버와 새 카드 이미지를 추가하지 않습니다.

질문에서 숫자·단위·일정·A/B 선택지와 확인 상태의 원문 위치를 남깁니다. 인용문, 가정·미확인 표현, 부정된 숫자와 과거 조건은 현재의 확보 자원으로 쓰지 않습니다. 수치를 변환·차감하거나 상대방의 시간을 내 시간으로 바꾸지 않습니다. 제한된 문법이므로 모든 생략·주체·시간 범위를 이해한다고 주장하지 않습니다.

실제 카드의 정·역방향 세부 주제와 카드 사이의 연결에서 관점을 고르고, 설명·질문 준비·조건 확인·실천·감정·선택 비교에 적용합니다. 두 카드의 관계를 쓸 때는 그 두 카드의 참조를 남기며, 관계에 없는 조언 카드의 주제로 바꾸지 않습니다. A/B의 각 카드 관점은 해당 라벨의 선택지에만 적용합니다. 비교 배열이 아니면 임의의 두 카드를 A/B의 결과로 지정하지 않습니다.

개발 출력 검토에서 카드의 돌봄 관점이 실제 조건 확인을 덮는 퇴행을 찾았습니다. 핵심 요청과 명시된 상태를 먼저 유지하고 카드 관점을 더하도록 고쳤습니다. 이미 대조한 내용과 아직 대조 중인 내용을 구분하며, 의료·연락 거절·응급 상황의 기존 제한도 유지합니다. 원문의 숫자를 표시했다는 사실만으로 조언의 적합성이 입증되지는 않습니다.

기존 v83 질문 12개 × 8종을 개발 자료로 사용합니다. 근거 추출 속성 검사와 카드·방향·작업 조합 검사는 구현·참조 검사이며, 수천 개 사용자 질문의 품질 평가가 아닙니다. 후보를 고정한 뒤 별도 첫 질문 출력을 보존하고 실제 문장을 읽어야 합니다. 첫 출력을 보고 수정한 이후 자료는 회귀로 구분합니다. 전문 해석가의 독립 평가는 아직 없으며, 핵심 품질·외부 기기 목표 완료 뒤에 번역을 진행하는 순서를 유지합니다.
