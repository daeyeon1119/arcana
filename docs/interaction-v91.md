# v91: 카드 방향과 연결 근거

카드 이름과 추상적인 주제 목록을 반복하던 문장을, 실제 카드 의미와 배열 위치를 함께 읽는 문장으로 바꿨다. 정·역방향의 공통 주제 뒤에 역방향 고유 의미가 있는 경우 그 차이를 적용한다. 예를 들어 여황제 역방향은 돌봄이라는 공통 주제만 반복하지 않고 과잉 부담을 살핀다. 펜타클 5 역방향처럼 도움과 회복을 나타내는 방향도 그대로 유지한다.

두 카드 사이에서는 기존에 작성된 19개 연결 규칙만 사용한다. 실제 방향과 반대 방향을 구별하는 주제의 수, 첫 주제의 포함 정도, 기존 작성 순서로 연결을 고른다. 이는 설명 가능한 편집 규칙이며, 해석의 정확성·확률·우열을 뜻하지 않는다. 모든 서로 다른 카드의 방향 조합 24,024개에서 근거와 좌우 대칭을 검사했다. 기존 순서와 다른 선택은 108개였으며, 이를 108개 오류 수정으로 집계하지 않는다. 같은 주제가 있다는 이유로 타당한 연결 규칙을 덮어쓰지도 않는다.

선택지 A/B는 각 경로로 유지하며 둘이 동시에 작용한다고 합치지 않는다. 제약의 카드는 실제 문제가 있다는 단정으로, 미래의 카드는 확정된 결과로 쓰지 않는다. 질문의 사실·의도 분석과 실천 방법은 이 변경의 대상에 포함하지 않았다. 의료·금융·경계 침해·긴급 상황·이미 알려진 결과는 기존 보고서를 보존한다.

배열의 역할과 카드 전체 흐름을 함께 살펴야 한다는 편집 원칙은 [Waite 원전 Part III §7–8](https://en.wikisource.org/wiki/The_Pictorial_Key_to_the_Tarot/Part_3)을 참고했다. 여기서 정한 주제 분류와 선택 순서는 앱의 구현 판단이며 원전의 인용이나 검증된 예측 기법이 아니다. 원전의 시대적 편견이나 진단·확정적 예언은 도입하지 않았다.

## 실제 출력과 검토 범위

- 구현 고정: `cebbd561c7d58fc3fd231752f9007f3b01e41433`, 앱 SHA-256 `eba279cf4ce0ba46e2ba44221e412fa02a22f96481d4946a306d4bf15519918a`.
- 알려진 개발 질문·배열 24개와 v90의 같은 입력 보고서를 보존했다. 초기 수집기에서 두 번째 표적 카드를 잘못 배치한 출력도 삭제하지 않았다. 수정된 입력에서는 실제 제약·마음 위치에 카드를 두었고 최종 24개 대표 답변을 읽었다.
- 기존 320개 질문을 다시 실행했다. 행동 조언·사실·의도·분야는 모두 v90과 같았다. 바뀐 대표 답변 141개를 읽고 해시를 남겼다. 나머지 179개는 문자열 일치만 확인했으며 새 수동 검토로 세지 않았다. 모든 상세 단락을 읽었다는 뜻도 아니다.
- 구현 고정 뒤 새로 작성한 질문 20개를 8개 배열로 처음 실행했다. 총 160개 원출력은 `45a54e3`에 먼저 보존했다. 작성자와 검토자는 구현 에이전트이므로 독립 평가가 아니다. 5장 배열의 대표 답변 20개를 읽었고, 다른 7개 배열의 전체 문장을 모두 읽지는 않았다.

## 아직 해결하지 못한 문제

행사 분담을 시험 문제 풀이로 읽는 답변, 수채화 연습에 오답 확인을 권하는 답변, 읽지 않은 설명문을 먼저 읽어야 한다는 조건의 누락이 새 평가에서 드러났다. A안만 있는 비교에서 B안을 확인하지 않거나, 의료 경계를 지키면서도 요청한 진료 질문 준비를 제공하지 못하는 경우도 있었다. 새 평가의 약한 질문 ID와 실제 문장은 `test-results/interaction/v91-review.json`과 `test-results/interaction/first/readings.json`에 남겼다.

이번 변경은 이러한 질문을 위한 개별 분기를 추가하지 않았다. 다음 개선에서는 낯선 분야에서도 행위·대상·부정·주체와 생략된 요구를 구조적으로 이해하는 문제를 우선해야 한다. 카드 연결도 특정 작업과 느슨하게 이어지는 문장이 남아 있다. 자동 검사 통과나 작성자 검토만으로 전문 해석가와 동등하다고 판단할 수 없다.

원본 RWS 78장, 무료 오프라인 실행, 카드 매트의 간격과 펼친 카드 하단 이름 숨김은 유지한다. 실제 공개 배포본의 Chrome·모바일 화면 에뮬레이션·새 오프라인 탭을 검증한다. 실제 Android 터치·기기 저장·비행기 모드 사용은 별도의 미확인 항목이며, 에뮬레이션을 실제 휴대전화 검사로 기록하지 않는다.
