# v89 개발·검토 기록

한국어 형태소 분석기 Garu 0.11.0의 모델과 WASM을 원본 바이트로 앱 HTML 안에 포함합니다. 서버·API 키·WebGPU·별도 모델 설치 없이 같은 파일을 실행하는 경로입니다. [고정한 배포본과 출처·라이선스](../vendor/garu/README.md)를 보존하고 앱의 정보 화면에도 고지를 내장했습니다. 이는 단어·품사 분석기이며 자유 생성 언어모델이나 전문 타로 해석 모델이 아닙니다.

단어의 일부 문자열과 실제 낱말, 명사 조사와 관형절, 다른 사람의 사건과 별개인 제 작업을 구분하도록 연결했습니다. 명시적인 결과물·마지막 동작이 목적문보다 앞서며, 목적이 있는 일반적인 준비 요청은 그 목적을 이어받습니다. 미독 회신의 확인 순서와 이미 읽은 답변에 연결한 질문 준비도 보완했습니다. 설명을 단순히 언급한 문장을 실제 전달 방법으로 인정하지 않되, ‘말+하다’ 같은 명사 동사 결합과 기존 구체적인 실천 방법은 보존합니다.

의료진에게 상황을 전하는 실용 안내는 증상·시작 시점·빈도·변화를 정리하는 범위입니다. 진단·치료·복약 변경을 카드로 판단하지 않습니다. 이 일반적인 진료 대화 준비는 [NIH/NIA의 진료 대화 안내](https://www.nia.nih.gov/health/five-ways-get-most-out-your-doctors-visit)를 참고했으며, 질문에 없는 환자 상태·검사 결과는 만들지 않습니다.

## 개발 자료와 보존한 실패

구현 전 [v88의 24개 질문×8배열](../test-results/lexical/baseline/readings.json)과 최초 계약 실패를 커밋 `91791b4`에 보존했습니다. 구현 후의 [같은 질문 실제 출력](../test-results/lexical/development/review.html)과 [직접 읽은 범위](../test-results/lexical/development/review-scope.json)는 별도 기록합니다. 원래 평가에 없던 의료 설명 내용 계약은 실제 부족한 답변을 읽은 뒤 회귀 검사로 추가했습니다. 이 자료는 알려진 개발 자료이며 새로운 독립 평가가 아닙니다.

- [초기 분야 손실](../test-results/lexical/development/initial-routing-regressions.json): 작은 어휘 목록에 없다는 이유로 기존 분야를 지워 33개 분류를 바꾸고 의료 질문도 놓쳤습니다. 부재를 반증으로 쓰지 않고, 명백한 단어·역할의 반증이 있을 때만 해당 단어를 제외한 재분류를 사용하도록 수정했습니다. 전체 320개 중간 출력은 압축 원본으로 보존합니다.
- [문자 위치 오류](../test-results/lexical/development/unicode-offset-initial.json): 분석기의 Unicode scalar 위치를 JavaScript UTF-16 위치로 오인했습니다. 변환을 추가하고 이모지·결합 문자·실제 인용문을 검사했습니다. 형태소 위치가 아닌 어절 전체 위치라는 구분도 유지합니다.
- [목적문 우선순위 오류](../test-results/lexical/development/initial-purpose-regression.json): 학생에게 물어볼 질문을 준비하는 요청을 앞선 이해도 확인 목적으로 덮었습니다. 명시적 결과물을 우선하도록 수정하고 최초 실패 8개 배열을 남겼습니다.
- [설명 명사와 실제 동작](../test-results/lexical/development/initial-communication-support-failure.json), [동사 결합 누락 회귀](../test-results/lexical/development/initial-communication-predicate-regressions.json): 단순 명사 언급은 거절하면서도 실제 발화·상의 동작의 명사+하다 결합을 인정하도록 보완했습니다. 구체적인 반환 요청 등을 일반론으로 바꾼 중간 출력도 보존합니다.
- [외국어 이름의 주체 누락](../test-results/lexical/development/foreign-actor-initial.json): 외국어·한자 명사 품사를 주체 후보에서 빠뜨려 다른 사람의 수신을 사용자의 수신으로 바꿨습니다. 조사와 함께 쓰인 외국어 명사도 포함했습니다. [상의할의 잘못된 형태소 분리](../test-results/lexical/development/verb-surface-initial.json)는 실제 동사 품사와 명확한 동사 표기 형태를 함께 확인해 보완했습니다. 모델 출력도 항상 맞는 것으로 간주하지 않습니다.

## 현재 남은 의미 품질 한계

개발 핵심 답변 24개를 직접 읽었습니다. 단어·주체·목적 계약이 통과해도 해석 품질 통과가 아닙니다. 답변 편집의 깊이(k02), 질문에 없는 검사 결과 강조(k05), 긴급 안내 뒤 카드 주제 덧붙임(k07), 서류 설명 대상(k10), 관계 조율을 업무 분담처럼 쓰는 문장(k11), 투자와 지출의 혼동(k13), 성찰 요청의 구체성(k15~k17), 약한 카드 적용(k18), 끝낸 작업의 기준(k19), 두 단계 질문 준비의 구분(k24)이 남습니다. 다양한 분야의 일반적·반복적인 조언도 아직 전문가 목표에 미달합니다.

기존 320개 답변의 달라진 핵심 문장과 의료 질문 대조군을 따로 읽고 기록합니다. 모든 상세 보고서·모든 배열을 직접 다시 읽었다고 주장하지 않습니다. 자동 계약, 작성자 자체 검토, 구현 고정 뒤 새 질문의 첫 실행, 독립 전문가 평가는 구별합니다.

## 검증 범위

현재 HTTP 데스크톱·표준 모바일 에뮬레이션, 서버 없는 새 `file://` 문서, 새 오프라인 탭에서 24개 고정 질문·카드의 전체 보고서 일치를 확인했습니다. [실행 기록](../test-results/lexical/cold-summary.json). 외부 모델 요청이나 질문 전송은 관찰되지 않았고 고지 내용도 HTML에 포함됐습니다. 이 실행은 물리적 Android·Safari 검증이나 전문가 품질 검증을 대신하지 않습니다.

최종 후보 고정·새 질문 첫 실행·전체 회귀·실제 공개 배포 검사는 이어서 기록합니다. 전문 해석가 수준의 목표와 이후 번역 작업은 아직 완료되지 않았습니다.
