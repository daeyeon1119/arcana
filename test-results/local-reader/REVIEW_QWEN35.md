# 두 번째 무료 로컬 모델의 개발 질문 검토

Qwen3.5-9B-Q4_K_M을 같은 기기에서 실행해 **기존 개발 질문 3개**의 단일 단계 답변과 **그중 1개**의 두 단계 답변을 모두 읽었습니다. 새로운 질문의 성능이나 전문가 수준을 검증한 결과가 아닙니다. 두 방식 모두 기본 앱에 채택하지 않았습니다. 외부 전문가의 평가는 없습니다.

| 실행 | 실제 답변 | 구조 검사 | 실제 문장 검토 |
|---|---:|---:|---|
| [단일 단계](native-qwen35-9b-first/development-v1/review.html) | 3개 | 3개 통과 | 3개 모두 큰 보완 필요 |
| [질문 분석 후 해석](native-qwen35-9b-staged-first/development-v1/review.html) | 1개 | 1개 실패 | 질문 분석은 요청을 짚었으나 해석에 근거 없는 사실·인과관계와 요청 미충족이 남음 |

‘큰 보완 필요’는 저자의 실제 문장 검토 결론이며 독립 평가 점수가 아닙니다. 원본 JSON의 자동 집계 `qualityReviewed: 0`은 생성기가 품질 점수를 만들지 않았다는 뜻입니다. 사후 읽은 내용은 별도 `review-notes.json`에 보존합니다.

단일 단계에서는 저축 조건 확인을 일정·지출 문제로 바꾸고, 진료에서 질문을 잊는 문제를 증상 기록으로 바꾸며, 사과 후 대화가 늘어난 배경에 확인되지 않은 동등한 신뢰를 붙였습니다. 두 단계에서는 카드 없는 분석이 ‘조건·기준 확인’이라는 요청을 보존했지만 최종 답변이 원문 질문을 답 대신 반복했습니다. ‘과거의 균형 감각이 현재 재정적 불안감을 만들고’라는 인과관계도 지어냈습니다. 카드 이름을 원문에 없는 추가 요청의 출처로 쓴 것은 인용 검사에서 검출됐습니다.

## 실행 범위와 재현

- 모델·실행 파일의 바이트 수와 SHA-256을 확인했습니다. 모델은 6,169,341,984바이트이며 작업 폴더의 캐시에만 있습니다. 모델 가중치·실행 파일은 Git에 올리지 않습니다.
- 후보 설정을 `f75aebf`에서 고정했습니다. 기존 계약과 프롬프트는 변경하지 않았습니다. 샘플링과 컨텍스트 길이도 이전 후보와 달라 **모델 크기만의 효과를 분리한 비교가 아닙니다**.
- 단일 단계 3개는 각각 약 282.1초·177.6초·185.5초, 두 단계 1개는 합계 약 291.7초가 걸렸습니다. 이 기기의 4개 CPU 스레드를 사용한 결과입니다. 더 빠른 기기나 다른 질문의 속도를 보장하지 않습니다.
- 모델 실행 중 관찰한 사용 가능 메모리는 약 0.34GiB까지 줄었습니다. 완료한 소수 질문은 실행 가능성을 보여줄 뿐, 일반 기기의 안정성을 입증하지 않습니다.
- 실행·전송 오류 없이 4개 답변을 받았습니다. 처음 받은 답변을 수정하거나 더 좋은 재시도로 대체하지 않았습니다.
- 새 질문 14개는 설정 고정 후, 첫 답변을 받기 전 `ae5deaa`에 별도 저장했습니다. 같은 카드에서 바꿔 말하기·접수 완료/예정·수신/발신·연락 동의를 바꾼 쌍과 새 분야·복합 요청·10장 배열을 포함합니다. **아직 이 14개의 답변을 생성하거나 평가하지 않았습니다.** 개발 단계에서 채택 기준을 만족하지 못했으므로 이 파일을 새 질문 성능의 근거로 쓰지 않습니다.

다음 후보는 질문 분석의 결과가 최종 해석에서 사라지는 문제와 카드 상징이 실제 사실로 변하는 문제를 구조적으로 다뤄야 합니다. 이 네 답변에만 맞춘 예외나 정답 대체문을 앱에 추가하지 않았습니다.
